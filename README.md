# Circle Cleaner Plugin (exteraGram / AyuGram Android)

Плагин для **exteraGram** и **AyuGram (Android)** для быстрого выборочного или полного удаления видеосообщений (кружочков) из любого чата прямо через кнопку меню **Plugins**.

---

## ⚡ Быстрая установка (в 1 клик)

1. Скачайте готовый файл плагина:  
   👉 **[Скачать circle_cleaner.plugin](https://raw.githubusercontent.com/Mor4land/circle-cleaner/main/circle_cleaner.plugin)**
2. Отправьте скачанный файл себе в **«Избранное» (Saved Messages)** в Telegram/exteraGram.
3. Нажмите на файл в чате и подтвердите установку: **«Установить плагин» (Install Plugin)**.

---

## 📱 Как пользоваться

### Способ 1: Через кнопку в меню (Рекомендуется)
1. Откройте любой диалог, группу или канал.
2. Нажмите меню **«3 точки»** в правом верхнем углу.
3. Перейдите в **Plugins** → **Удалить кружочки**.
4. Во всплывающем окне выберите:
   - **[Все кружки]** — удалить абсолютно все кружки в чате.
   - **[Только мои]** — удалить только кружки, отправленные вами.
   - **[Отмена]** — закрыть окно.

*(Также доступно при долгом тапе по любому сообщению: контекстное меню → Plugins → Очистить кружки в чате).*

---

### Способ 2: Текстовые команды в чате
Сообщение с командой перехватывается плагином и не отправляется собеседнику:
* `.delcircles` — удалить кружки согласно настройкам плагина.
* `.delcircles my` — удалить только ваши кружки.
* `.delcircles all` — удалить все кружки в чате.
* `.delcircles 20` — удалить до 20 последних кружков.
* `.delcircles my 50` — удалить до 50 последних ваших кружков.
* `.delcircles stop` — мгновенно остановить запущенный процесс удаления.

---

## ⚙️ Настройки
В **Настройки → Настройки exteraGram → Плагины → Circle Cleaner**:
- **Удалять только свои кружки по умолчанию**: переключение режима по умолчанию.
- **Удалять для всех участников (Revoke)**: удалять сообщения у обоих собеседников в личных чатах и группах.
