# Circle Cleaner Plugin (exteraGram / AyuGram Android)

Плагин для **exteraGram** и **AyuGram (Android)** для быстрого выборочного или полного удаления видеосообщений (кружочков) из любого чата прямо через интерфейс приложения.

---

## ⚡ Скачать готовый плагин (Releases)

👉 **[Скачать circle_cleaner.plugin (v1.4.1)](https://github.com/Mor4land/circle-cleaner/releases/download/v1.4.1/circle_cleaner.plugin)**

*Страница релиза:* [v1.4.1 Release](https://github.com/Mor4land/circle-cleaner/releases/tag/v1.4.1)

### Установка в 1 клик:
1. Скачайте файл `circle_cleaner.plugin` по ссылке выше.
2. Отправьте скачанный файл себе в **«Избранное» (Saved Messages)** в Telegram / exteraGram.
3. Нажмите на файл в чате и нажмите **«Установить плагин» (Install Plugin)**.

---

## 📱 Где находится кнопка в приложении

Кнопка зарегистрирована сразу во всех возможных меню:

1. **При долгом нажатии (тапе) на любое сообщение в чате:**
   В появившемся контекстном меню сообщений внизу будет пункт **«Удалить кружки в чате»**.
2. **В меню чата «3 точки» вверху:**
   Нажмите «3 точки» в правом верхнем углу чата → подменю **Plugins** → **«Удалить кружочки»**.
3. **В профиле чата / собеседника:**
   Откройте профиль → «3 точки» → **«Удалить кружочки»**.
4. **В главном меню (список чатов):**
   «3 точки» на главном экране списка чатов → **Circle Cleaner**.

---

## 💡 Выбор режима удаления

При нажатии на кнопку появляется диалоговое окно Telegram:
- **[Все кружки]** — удалить абсолютно все кружки всех участников в текущем чате.
- **[Только мои]** — удалить только кружки, отправленные вами.
- **[Отмена]** — закрыть окно.

### Прогресс поиска и сканирования:
Плагин показывает живой индикатор:
- Сначала выполняет быстрый поиск через серверные фильтры.
- Если серверный поиск возвращает 0 результатов (или в чате не проиндексированы медиа), плагин **автоматически запускает глубокое сканирование истории сообщений** с живым счетчиком:
  `Проверено сообщений: 400 | Найдено кружков: 12`.
- Во время процесса доступна кнопка **[Остановить]** для отмены в любой момент.

## ⌨️ Резервные текстовые команды (опционально)
Сообщение с командой перехватывается плагином и не отправляется собеседнику:
* `.delcircles` — запуск удаления согласно настройкам плагина.
* `.delcircles my` — удалить только свои кружки.
* `.delcircles all` — удалить все кружки в чате.
* `.delcircles 20` — удалить до 20 последних кружков.
* `.delcircles my 50` — удалить до 50 последних ваших кружков.
* `.delcircles stop` — остановить удаление.

---

## ⚙️ Настройки плагина
В **Настройки → Плагины → Circle Cleaner**:
- **Удалять только свои кружки по умолчанию**: переключение режима по умолчанию.
- **Удалять для всех участников (Revoke)**: удалять сообщения у обоих собеседников в личных чатах и группах.
